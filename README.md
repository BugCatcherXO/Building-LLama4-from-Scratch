Building-LLama4-from-Scratch

Exploración técnica desde cero de los componentes clave de LLaMA 4: 
Multi-Head Latent Attention (MLA), bloques feed-forward y tokenizer. 
Cada módulo en archivos independientes con notebooks explicativos para 
profundizar en los mecanismos internos del modelo y entender qué hace 
diferente a LLaMA 4 respecto a arquitecturas anteriores.

Habilidades: PyTorch, arquitectura de Transformers, Multi-Head Latent 
Attention (MLA), tokenización, fundamentos de attention, comprensión 
profunda de LLMs SOTA.
